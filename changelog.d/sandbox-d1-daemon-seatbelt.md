- **On macOS, the Kaimon server and the `julia-update` job run under a Seatbelt profile.** Code that a session runs through Kaimon's `ex` can no longer read the home directory outside `~/Research`, the Julia depot, juliaup, Kaimon's own directories and git's configuration, and cannot write the depot's `bin/` and `config/`, juliaup's state, the harness's `githooks/`, or `.git/hooks`, `.git/config` and `.githooks` below `~/Research`; opening an app through Launch Services, an Apple Event and a mount are denied. The network and the Mach services, which Metal needs, stay open. The rules of both jobs are in `sandbox/daemon.toml`; `harness render sandbox/<job>.sb` prints a job's profile with the profile's home and the per-user directories of `getconf`, and `harness setup` and the dotfiles kit write it into `~/.config/research-harness/sandbox/` before they load the job, whose plist starts it with `/usr/bin/sandbox-exec -f`. Run `harness setup` with the component `jobs` to install the profiles and load both jobs again; `sandbox/probe-daemon.jl` holds the probes that show the profile at work through `ex`.
