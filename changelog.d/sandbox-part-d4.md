- **Two of Kaimon's sandbox probes measure the sandbox again on Linux.** `read_research` in `sandbox/probe-daemon.jl` reads `~/Research/Harness/README.md`, a file that every tree of the harness holds, in place of the first file at the top of `~/Research`: a `~/Research` that holds only directories there gave `:ErrorException` in and outside the job. `write_zshrc` takes a keyword `linux`, which defaults to the running system; on Linux it gives `:NotBound`, a new exception class of the probe file, where the job's home holds no regular `~/.zshrc`, and opens nothing. The job's home is a `tmpfs` that holds only the job's binds, so the append made a new file there, gave `:allowed` and never reached the host's file. A `:NotBound` result measures nothing: it is neither a pass nor a gap. The probe cases of `harness test jobsandbox` run both probes on a scratch `~/Research` that holds only directories at its top level, and `write_zshrc` with `linux` true and false, on a home with and without a `~/.zshrc`, and on one whose `~/.zshrc` is a directory or a dangling link.
