- **Claude Code under `agentbox` reads its Anthropic profile and can refresh its token, and `agy`'s token file is readable in `agy`'s `srt` settings only.** `sandbox/policy.toml` gives `claude` the `state` paths `~/.config/anthropic/credentials` and `~/.config/anthropic/credentials.lock`, the lock directory that Claude Code makes before a token refresh, and the `own` path `~/.config/anthropic/credentials`; it gives `antigravity` the `own` path `~/.gemini/jetski-standalone-oauth-token`. The settings template denies reads of both paths and names them in `credentials.files`, so every other frontend's `srt` settings and Claude Code's own sandbox deny them. A frontend's `srt` settings now leave out each literal write deny of the template that lies strictly above one of its `state` paths, because `srt` emits the write denies after the allows: so `claude`'s file has no write deny `~/.config`, and keeps `~/.config/systemd/user`. Before, the first API call under `agentbox claude` failed on the `mkdir` of the lock.
