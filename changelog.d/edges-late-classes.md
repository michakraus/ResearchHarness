- **`skills/build-part/edges.md` names three more edge classes that critics found late.** A file
  that an installer copies into another repository and that fails that repository's own gate; an
  empty base in `git diff BASE...HEAD`, which git reads as `HEAD...HEAD`, so a selection of
  changed paths passes on no evidence; and a child started in a session of its own, which a
  SIGTERM or SIGHUP of its parent leaves running. `plan-parts` writes a part's *Decided at the
  edges* from this list, so the next part of each kind decides these before its build.
