- **`skills/build-part/edges.md` names five more edge classes from the E5g and D2 loops of the
  sandbox plan.** A deny added to a sandbox's file list and not to the frontends' own read-tool
  denies; a path rule tested only in the spelling that the code compares; a link check on the bind
  sources of one kind or below one tree; pins against a live writer computed from the other job's
  sources only, where a pin is a bind source too and a later bind of a parent path covers an
  earlier pin; and a rule "at or below a path" tested only strictly below it. `plan-parts` writes
  a part's *Decided at the edges* from this list, so the next part of each kind decides these
  before its build.
