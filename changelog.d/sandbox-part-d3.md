- **Kaimon's Julia sessions get a PoCL kernel cache of their own.** Kaimon's plist and unit set `POCL_CACHE_DIR` to `~/.cache/kaimon/pocl`, and `harness setup` creates that directory, each directory that it creates with mode 700, before it loads the Kaimon job; so do the services script of the dotfiles kit and the commands by hand of the jobs step in the setup reference. Kaimon's Seatbelt profile denies PoCL's default `~/.cache/pocl`, so a KernelAbstractions CPU kernel that the cache did not hold failed in a Kaimon session with `CLError(1)`; the sandbox of a Bash command may write `~/.cache/pocl`, and that cache stays apart from the one that Kaimon loads and runs. Run `harness setup` with the component `jobs` to create the directory and reload the job.
