- **`core.md` requires every reference to be checked against its record before it is cited.**
  Some models write references from memory that do not exist or carry wrong metadata. The new
  section applies to every place a reference is written — code, notes, documentation, BibTeX,
  manuscripts, PR text and replies — and names the record for each kind of identifier: Crossref
  for a DOI, the arXiv abstract page for an arXiv identifier, ISBN, zbMATH or MathSciNet for a
  book, and a title-and-author search where there is no identifier. A reference with no record is
  left out or marked unverified and named in the report.
