- **`harness setup` asks for the frontends and the components from a checkbox list in a terminal.** The list starts at the current choice; the arrow keys move, space checks or unchecks a name, Enter accepts, and one line after the list names the choice, so that the scrollback of an SSH session holds it. The list uses the standard library's `curses`, which loads only for the list. The numbered list stays where standard input or standard output is no terminal, where `TERM` is unset, empty or `dumb`, where Python has no `curses` or it cannot set up the terminal, and where the window has too few rows.
