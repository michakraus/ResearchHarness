- **`skills/build-part/edges.md` names two more edge classes from two arbitrator rulings.** A path
  check written per segment whose exemption for one form, added in a fix round, let a path with a
  final `/` through; and a check that a symbolic link stays inside a tree, made on the normalised
  path, which keeps the directory name that the move renames. Both show that a fix round that adds
  a check can regress an edge of that check itself. `plan-parts` writes a part's *Decided at the
  edges* from this list, so the next part of each kind decides these before its build.
