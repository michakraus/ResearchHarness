- **`skills/build-part/edges.md` names two more edge classes from the J7b loop.** A table of a
  program's options that knows only the `=` form of a valued option, and a reader of shell commands
  that takes a reserved word such as `then`, `do` or `!` for the program. `plan-parts` writes a
  part's *Decided at the edges* from this list, so the next part of each kind decides these before
  its build.
