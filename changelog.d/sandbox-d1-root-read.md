- **The Seatbelt profiles of the Kaimon server and the `julia-update` job let a process start.** Both profiles denied a read of the root directory `/` itself, which dyld reads when a process starts, so every process under them aborted at start-up and launchd restarted the Kaimon server without end. `sandbox/daemon.toml` now lists `/` as a read file of both jobs, a single path and not the tree below it, and `harness test jobsandbox` starts `/bin/sh -c true` under each rendered profile, or prints a skip line where `sandbox-exec` cannot apply a profile. Run `harness setup` with the component `jobs` to render the profiles again and reload both jobs.
