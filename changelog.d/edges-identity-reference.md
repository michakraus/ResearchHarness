- **`skills/build-part/edges.md` names the edge of a reference solved by a variant's own
  method.** A reference solved by the same method from the same start as one of the variants it
  measures gives that row an error of exactly `0.0` at a size where one step meets both
  tolerances, and a table reads the identity as agreement. `plan-parts` writes a part's *Decided
  at the edges* from this list, so the next measurement part checks the row at a second size
  before its table or a comment states the claim.
