- **`agentbox <frontend> [args…]` starts `claude`, `opencode`, `omp` or `agy` under the sandbox runtime `srt`, and `harness install` copies it to `~/.local/bin/agentbox`.** The new POSIX `sh` script `sandbox/agentbox` runs `~/.local/bin/srt --settings ~/.config/research-harness/sandbox/<frontend>.json -- <program> …` with the frontend's own settings file (`antigravity.json` for `agy`), the program from the `PATH`, and the caller's arguments unchanged. Claude Code gets `--settings ~/.config/research-harness/sandbox/claude-inner-off.json`, which `harness install` writes when `claude` is chosen and which turns its own sandbox off, since it fails inside `srt`'s; OpenCode gets `--standalone`, so its server runs inside the sandbox; oh-my-pi gets `--approval-mode yolo`. The frontend sees `AGENTBOX=1`. `agentbox` exits 2 with one line, and starts nothing, for an unknown frontend, a run inside `agentbox`, a missing `srt` (run `harness setup`), a missing settings file (run `harness install --apply`), a program not on the `PATH`, and a `--settings` of the caller's for `claude`. The launcher has mode 755, and a different mode of the installed copy is a change.
