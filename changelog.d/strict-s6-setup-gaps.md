- **`harness setup` closes the gaps that a clean Ubuntu install left to the user.** With the component `jobs`, the new optional profile key `claude_remote` names the `~/.claude` repository: a terminal run asks for it, the plan clones it into a missing or empty `~/.claude` as its first step, before any installer can write below `~/.claude`, and without it no autocommit job is rendered or enabled (the `claude-autocommit` script is still copied), so `harness doctor` reports the job `SKIP` instead of a `FAIL`. After the jobs start the Kaimon server, the token step waits up to 60 s for the server's key. The plan prints one `export PATH=…` line for the directories of the installed tools that the starting `PATH` lacks, and with zsh as the login shell asks y/N to append it to `~/.zshrc`; a `~/.zshrc` that holds the line already gets no second copy. On Ubuntu without an apt candidate, chezmoi installs from its pinned release 2.73.2. The Antigravity line by hand says to run `harness install --apply` after the app's first start, and `harness doctor` prints every line of an install warning, the further lines indented below its `WARN` line.
