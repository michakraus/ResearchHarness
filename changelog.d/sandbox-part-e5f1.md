- **Kaimon's Seatbelt profile closes the network but loopback on macOS.** A job of `sandbox/daemon.toml` has two keys more, `network` (`"open"` or `"loopback"`) and `unix_sockets`; Kaimon gets `"loopback"` and `~/.cache/kaimon`, and its profile ends with `(deny network-outbound)`, an allow of `127.0.0.1` and `::1`, and an allow of the Unix sockets below `~/.cache/kaimon`, where its server and sessions talk. Code that runs through Kaimon's `ex` reaches no host on the network, and Kaimon's plist sets `JULIA_PKG_OFFLINE=true`, so a `Pkg.add` in a session that needs a download fails: run it from a session's own `julia`, or let `julia-update` install it, which keeps the network. `sandbox/probe-daemon.jl` adds the probes `connect_loopback`, `pkg_offline`, `connect_remote` and `resolve_name`. Linux keeps the network. Run `harness setup` with the component `jobs` to render the profile and reload the job.
