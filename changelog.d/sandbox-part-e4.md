- **`scripts/probe-agentbox.py` is the probe battery of the CLI frontends under `agentbox`: it checks that each frontend's srt settings file holds the boundary that the policy means.** The user runs `python3.14 scripts/probe-agentbox.py [--out DIR] [--timeout S] [--no-model] [FRONTEND …]` from a plain terminal on macOS, after `harness setup` and `harness install --apply`; it exits 2 and runs nothing inside a sandbox, on another platform, for an unknown argument, or with `srt`, `agentbox` or a settings file missing. For each of `claude`, `opencode`, `omp` and `agy` it asks each listener on `127.0.0.1`, on `::1` or on every interface for authentication, runs 39 read, write, network and process probes as `/bin/sh -c` under `~/.local/bin/srt` with the frontend's settings file, and, unless `--no-model`, the frontend probes F1–F7 through `agentbox` with a time limit. Each probe is harmless where the sandbox fails: a read prints a count, an append writes nothing, a created file is deleted, and the launchd job and the devfs mount of a probe are removed. The expected value is the policy's intent, so a `MISMATCH` is a finding for the policy. The script writes `report.tsv` and `report.md` below `~/Research/.scratch/agentbox-probes/` and exits 1 on a `MISMATCH` or a `timeout`. `harness test` runs its cases with stubs of every program, so no case starts a sandbox, a frontend, an app or a launchd job.
