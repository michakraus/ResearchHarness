- **`skills/build-part/edges.md` names two more edge classes from the VC and CH loops.** A
  verification test that reads a hypothesis of its theorem at a point, or trusts a user-supplied
  derivative on the box, and so certifies a box with no root; and a literal element-type tuple in
  a test loop header that the repository's own matrix check refuses, which a round that runs only
  the part's test file does not see. `plan-parts` writes a part's *Decided at the edges* from this
  list, so the next part of each kind decides these before its build.
