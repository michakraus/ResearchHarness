- **`skills/build-part/edges.md` names five more edge classes from the B3 and B1 loops.** A map
  that reuses a source text keyed by the value, which two readers read differently (`-0` and `0`);
  a second reader that decides a certainty but has a narrower domain and does not fail closed; an
  error located by a walk of the text in another order than the parser's; a spec check that reads
  the output of a command whose option sends the lines to a file; and a lookup by name through a
  view that leaves the field out. `plan-parts` writes a part's *Decided at the edges* from this
  list, so the next part of each kind decides these before its build.
