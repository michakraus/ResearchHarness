- **`skills/build-part/edges.md` names seven more edge classes that the loops found late.** A
  post-PASS fix committed on top of a release commit, a page that a branch makes false outside the
  part's file list, a cost premise that times a generated function's build and never calls it, a
  docstring `@extref` link where the docs define no inter-links, a text fix generalised from one
  verified instance to its neighbours, an allocation reading through an entry point that rebuilds
  its state, and a page sentence that has `@docs` render a name that moved to another package.
  `plan-parts` writes a part's *Decided at the edges* from this list, so the next part of each kind
  decides these before its build.
