- **`agentbox` skips cmux's shims when it looks up a frontend, and gives each run its own npm, uv and LaTeX caches.** In a cmux terminal the first `claude` on the `PATH` is a cmux shim that `srt` cannot read, so `agentbox` now resolves each program with `command -v` on the `PATH` without the entries that match `*/cmux-cli-shims/*` or `*/cmux-cli-shims`; the program still gets the caller's `PATH`. A result that does not start with `/`, such as an exported bash function named like a frontend, is refused with status 2. Each run makes one directory with `mktemp -d "${TMPDIR:-/tmp}/agentbox.XXXXXX"` and sets `npm_config_cache`, `UV_CACHE_DIR` and `TEXMFVAR` to its subdirectories `npm`, `uv` and `texmf-var` where the caller's variable is unset or empty, since the sandbox denies these caches in the home directory; a `$TMPDIR` in which `mktemp` cannot make the directory is refused. The docs page also states that a symlinked `~/.local/bin` stops `harness install --apply`, since the install writes nothing through a symlink.
