- **`skills/build-part/edges.md` names two more edge classes from the P1 loop.** A port whose
  messages print a parsed value in the spelling of its own language, where the source language
  spells a list, a mapping entry or a float another way; and a decided edge on a parsed value that
  the port checks for one node kind only. `plan-parts` writes a part's *Decided at the edges* from
  this list, so the next part of each kind decides these before its build.
