- **Kaimon starts Julia sessions under its Seatbelt profile.** Kaimon starts every session on a pseudo-terminal with `forkpty`, and the profile denied the writes to `/dev/ptmx` and `/dev/ttysNNN`, so `start_session` failed with "Spawn failed: forkpty failed: Operation not permitted". A new required key of each job in `sandbox/daemon.toml`, `pty`, is `true` for Kaimon and `false` for `julia-update`; with `true`, the profile allows the operation `pseudo-tty` and reads, writes and ioctls of `/dev/ptmx` and of every `/dev/ttysNNN`, before the write denies. Seatbelt cannot tell the job's own pseudo-terminal from another terminal of the same user, so a process under Kaimon's profile can write into any terminal window of the user; `docs/src/security.md` states what this leaves open. `harness test jobsandbox` also opens a pseudo-terminal and forks a shell on one under Kaimon's profile. Run `harness setup` with the component `jobs` to render the profiles again and reload both jobs.
