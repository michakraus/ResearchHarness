- **`skills/build-part/edges.md` names three more edge classes that critics found late.** A
  guard's phrase that a library error also writes, such as "a matrix of size" in Base's
  matrix-product error, so a substring test passes when the guard is removed: assert the whole
  message with an anchored pattern. A dense solve on a device array, such as `lu!`, which looks
  device-capable because its buffers sit on the device and raises "Scalar indexing is disallowed".
  A `KNOWN_ISSUES.md` number that `main` or an open pull request takes while a branch is open.
  `plan-parts` writes a part's *Decided at the edges* from this list, so the next part of each kind
  decides these before its build.
