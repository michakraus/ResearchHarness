- **Kaimon keeps its Julia sessions under its Seatbelt profile.** Kaimon checks that a session's process lives with `ps -o state= -p PID`, and the exec of the setuid `/bin/ps` fails under a Seatbelt profile, so the server deleted the metadata of every live session and `start_session` timed out. `harness setup` and the dotfiles kit now install `sandbox/shims/ps`, mode 755, into `~/.config/research-harness/sandbox/shims/`, which Kaimon's plist puts first on the job's `PATH` and Kaimon's profile reads and does not write. The shim prints `S` where `kill -0 PID` succeeds and exits 1 otherwise, exits 1 with no output for Kaimon's `-o rss=,%cpu= -p PID`, and exits 2 for any other form; it counts a zombie as alive and a process that `kill -0` may not signal as gone. Run `harness setup` with the component `jobs` to install the shim, render the profiles again and reload both jobs.
