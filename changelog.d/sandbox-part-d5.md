- **Kaimon's read probes give `:NotAFile` where a directory stands at their path (K165).** `read_only` in `sandbox/probe-daemon.jl` opens the path and raises `NotAFile`, a new exception class of the probe file, when the open stream is not a regular file; it reads a link to a regular file as that file. `read` of a directory returned no bytes and threw nothing on macOS, so `read_research`, `read_claude_json` and `read_gh_hosts` gave `:allowed` where no file was read: a negative probe reported a gap and a positive probe a pass that measured nothing. A `:NotAFile` result is neither a pass nor a gap. The check reads the open stream, so a sandbox that refuses the open still gives its own class. The probe cases of `harness test jobsandbox` put a directory at the path of each of the three probes and a link at that of `read_claude_json`.
