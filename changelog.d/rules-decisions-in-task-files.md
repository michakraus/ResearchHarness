- **`rules/changelog.md` sends a decision for a repository on GitLab into the `Tasks/` file of the
  work that raises it, not to a standing `Tasks/Decisions pending.md`.** A queue of decisions cut
  off from their work is easy to overlook, and the decision loses the context it needs. The rule no
  longer cites a task file that the repository does not hold, so K73 lists three files, not four.
