- **The harness runs on Ubuntu 24.04, whose `python3` is 3.12 and whose Node.js is 18.** `bin/harness` starts on Python 3.9 or later: below 3.14 it goes on to `uv sync` with `UV_PYTHON=3.14`, so uv downloads Python 3.14 for the Python environment, and it runs no command on the older interpreter; it exits 2 below 3.9, and in a session with no environment, where it says to run `harness` once in a plain terminal. With `UV_PYTHON_DOWNLOADS=never` and a sync that fails, a second line names `uv python install 3.14`. `harness doctor` reports a `python3` below 3.14 as a `WARN` when the environment's interpreter is 3.14 or later. Where the apt candidate of `nodejs` is below the minimum, `harness setup` installs the Node.js 24.22.2 release of nodejs.org that `setup/tools.toml` pins, after a check of its sha256: it unpacks the whole tree into `~/.local/share/research-harness/node/<version>/` with tarfile's `data` filter and links `node`, `npm` and `npx` into `~/.local/bin`. It installs nothing from an archive with an absolute member, a member that the filter refuses or a link that leaves the tree, and nothing where `~/.local/bin` holds a directory of one of the three names.
